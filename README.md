# homebrew-osint

Homebrew tap for [Bluetm.uz](https://github.com/Azizbek16l) OSINT tools.

## Install

```bash
brew tap Azizbek16l/osint
brew install mytools-osint
```

## What's here

| Formula | Description |
|---------|-------------|
| `mytools-osint` | Personal OSINT CLI — 24 modules, free APIs, red-team profiles, TUI, HTML reports |

## Update

```bash
brew update
brew upgrade mytools-osint
```
